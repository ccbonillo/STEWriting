# Examples: Before and After (English)

## Example 1: Procedure / Installation Steps

### Before (Non-STE)
You should basically first make sure that you've got administrative permissions on your machine, after which you can go ahead and open up your command prompt and start running the build script by typing in npm run build.

### After (STE)
1. Make sure that you have administrator permissions on your computer.
2. Open the command terminal.
3. Run the command: `npm run build`.

---

## Example 2: Descriptive Explanation

### Before (Non-STE)
The comprehensive multi-threaded server architecture handles all concurrent database queries by distributing them across several worker nodes in order to ensure optimal performance under heavy workloads.

### After (STE)
The server architecture uses multiple threads to process queries. It sends database queries to worker nodes. This architecture keeps system performance high during heavy workloads.

---

## Example 3: Safety / Warning

### Before (Non-STE)
Users are strongly advised not to abruptly disconnect the external drive without properly unmounting it first, as this might result in irreversible data corruption.

### After (STE)
> CAUTION: Do not disconnect the external drive before you unmount it. If you disconnect the drive early, data corruption can occur.
